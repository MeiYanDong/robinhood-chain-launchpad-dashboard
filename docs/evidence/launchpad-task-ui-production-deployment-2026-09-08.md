## 产品改动

1. 默认页只回答三件事：谁的成交量最大、谁相对自身平时最活跃、PAIR 相对 PONS 的规模锚差多少。完整经营、估值和代币信息移到对应任务页。
2. 平台经营页把“活跃度倍数”翻译为“最近 7 日平均 ÷ 过去正常水平”，同时保留 7 日、30 日、上线以来三个成交窗口；明细口径默认收起。
3. PAIR vs PONS 页直接展示公式、代入值、来源和共同闭合 UTC 日。七日预测只有在链况匹配、相似样本不少于 5 个且滚动回测中位误差不高于 50% 时才展示。
4. 当前线上 PONS 预测虽有 57 日价格观测和 8 个完整结果，但相似样本为 0，回测中位绝对误差约 110.71%；页面因此显示“暂无可靠七日预测”和“不展示”，没有把低质量结果伪装成价格结论。
5. 平台代币页保留 PAIR、Long 的底层配对资产；手机端默认概览改为卡片，避免关键比较表横向滚动。
