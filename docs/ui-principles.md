# 数据工具界面原则

## 默认视图

- 只展示完成当前判断所需的数据、控件、状态和会改变判断的警告。
- Robinhood Chain 发射台首页默认展示主流平台，以及成交量、用户手续费、平台收入三个指标。
- 主流平台以平台注册表中的 `live` 状态为准；其余平台通过“全部”查看。
- 桌面端使用紧凑表格，移动端使用三指标卡片，不依赖横向滚动。
- 相对估值首屏只显示实际价、锚点、区间、偏离、政策情景、置信度和走势；公式与限制留在数据说明。
- 全局导航只切换产品模块；发射台内部的数据集使用独立的二级导航，不重复全局入口。
- 三强对比先展示价格、市值、平台份额、协议收入和回购证据；完整经营表与逐笔核验按需展开。
- PAIR Alpha 首屏只展示当前动作通道、关键短窗数据、代际和风险；V2 当前 release 的机制与
  链上账本留在 `/pair-v2/`，跨代机会不混回机制页面。

## 按需信息

- 指标口径、来源健康、计算限制和平台审计说明必须保留，但默认折叠或放入“数据说明”。
- 平台详情默认展示三个核心指标和历史；范围、备注、来源链接放在折叠区。
- 通用 `Revenue` 继续保留在数据层，不进入默认界面，避免与平台收入混淆。
- 正常的官方、链上和第三方来源使用低噪音标记；范围不同、未核验、过期和不可用必须保持显著。

## 不进入产品界面的内容

- 宣言、口号、价值观式标题和装饰性章节编号。
- 重复解释当前页面已经能直接表达的内容。
- 中英双语包装标签、纯装饰副标题和方法论长文。
- 不会改变当前判断的覆盖率、来源或计算说明。
- 用于制造紧迫感但不能改变动作的涨幅口号；涨幅只能作为“过热勿追”或风险证据。

## 验收

- 用户打开首页后，无需阅读说明即可看到平台和三个核心指标。
- 首页不存在宣传性文案；错误和数据异常仍然明确可见。
- “数据说明”和平台详情能够追溯口径、来源及限制。
- 375px 宽度下不出现横向滚动，核心指标无需二次进入即可查看。
- 移动端全局入口固定在底部，页面内数据集保留在内容顶部，避免连续两排全局导航。
