# L-02 单平台回答 Lab

## 三案

### A｜核心三指标 + 独立快照（推荐）

先列请求窗口三指标，再单独列滚动 24H/累计快照，最后放质量与详情链接。收益是不会把 30d 和 rolling24h 混在一起；代价是略长；适合默认平台查询。

### B｜只显示有值指标

收益是短；代价是用户无法分辨未支持和 0，破坏 unknown 透明度；只适合非常窄的摘要，不采用。

### C｜按来源分组

收益是审计方便；代价是用户要自己合并同一指标；适合 /why，不适合默认。

## 决定

confirmed_decision: A。保留 unknown 行；revenue_usd 仅在用户明确点名 Revenue 时出现。
